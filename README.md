This repo contains the files I used while learning Machine Learning with python.
It covers the following:
1. [Foundations(Regression)](Phase%201/foundations.ipynb)

        2. EDA with Pandas
        3. Data Preprocessing: Missing data, scaling etc
        4. Cross-Validation.

2. [Classification](Phase%202/classifications.ipynb)
    - This includes:
        1. DecisionTrees
        2. RandomForest

        5. XGBoost and LightGBM

3. [Unsupervised Learning](Phase%203/clustering.ipynb)
    - This includes:
        1. K-Means Clustering
        2. PCA
        3. DBSCAN, t-SNE, Hiearchical Clustering
        4. Neural Networks
        5. API Basics - Flask Endpoints
